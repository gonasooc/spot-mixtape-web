# W-005 · 랜딩을 앱의 결로 — 리듬·서체·색 폭·밀도

- 상태: 완료
- 최근 갱신: 2026-10-04
- 관련 문서: [docs/design.md](../design.md), [docs/work/W-004-main-app-brand-alignment.md](W-004-main-app-brand-alignment.md), [PRODUCT.md](../../PRODUCT.md)

## 현재 상황

[W-004](W-004-main-app-brand-alignment.md)에서 요소(마크·색·파형·카드)와 원리 세 가지(제목 700·카드 그림자·화면 그라데이션)를 앱에 맞췄는데도 "앱은 자유롭고 랜딩은 모던하다"는 인상이 남았습니다. 남은 원인으로 짚은 네 가지 — 여백 리듬과 대칭 히어로, 한국어 서체의 성격, 색 폭, 콘텐츠 밀도 — 를 사용자 지시로 효과 큰 순서대로 모두 적용합니다. W-004가 지키던 "레이아웃 구조 유지"는 이 작업에서 해제됩니다.

- 완료 조건: 섹션 리듬이 개편 전 값(96/64px)으로 돌아가고 히어로가 카피+카드 비대칭 2단이 된다. 한국어 서체가 Outfit의 기하학적·둥근 성격에 가까운 OFL 글꼴로 바뀌고 self-host·라이선스 고지가 유지된다. 앱 팔레트의 violet·primaryMuted·의미색이 실제 쓰이는 자리에 들어간다. 사운드 카드가 앱 `SoundCard`의 해부(커버·장소·날짜·길이·상태)를 갖춘다. 빌드·토큰 검사 통과, 네 폭 넘침 0건.
- 사람이 판단할 사항: 서체 최종 선택. 후보 조사 결과와 선택 이유를 아래에 적고 진행하되, 다른 글꼴을 원하면 되돌릴 수 있게 `@theme`의 `--font-sans` 한 줄로 묶습니다.

## 진행과 판단

### 배경과 범위

W-004 마지막 비교에서 랜딩의 "모던함"을 만드는 요인 중 (a) 세 장치가 건드리지 않은 것들입니다. 각각의 근거: 섹션 간격 144/88px은 개편(`86069ad`)이 64/96에서 올린 값이고, 중앙 정렬 히어로도 개편이 비대칭 2단을 바꾼 것입니다. Pretendard는 중립 그로테스크라 Outfit의 기하학적 온기와 결이 다릅니다. 앱은 의미색을 39곳, primaryMuted 칩을 여러 곳에 쓰지만 랜딩은 애시드 하나입니다. 앱 카드는 커버·장소·날짜·길이·상태가 한 장에 있지만 랜딩 카드는 라벨과 파형뿐입니다.

### 중요한 시도와 결정

- 2026-10-04 — **서체.** 후보를 npm/jsDelivr에서 조사했습니다. Paperlogy·Freesentation(기하학적 한글, OFL)은 npm에 없고 GitHub 배포본은 분할되지 않은 2MB대 파일이라 제외. fontsource의 한글 글꼴은 Google Fonts처럼 unicode-range로 ~100조각 분할돼 Pretendard dynamic subset과 같은 방식으로 받습니다. 그중 Outfit의 기하학적·둥근 성격에 가장 가까우면서 400/500/700이 다 있는 **Gothic A1**(HanYang I&C, OFL 1.1, 9굵기, 99조각)을 골랐습니다. Sunflower는 더 둥글지만 400이 없고(300/500/700), Nanum Gothic은 500이 없으며, IBM Plex Sans KR은 휴머니스트라 결이 다릅니다. `@fontsource/gothic-a1` 400·500·700을 쓰고 `pretendard`는 제거했습니다. 교체는 `--font-sans` 한 줄이라 되돌리기 쉽습니다.
- 2026-10-04 — **폰트 인라인 금지.** 분할 글꼴은 조각이 많고 작아 Vite 기본값(4KB 미만 인라인)이면 수십 개가 `data:` URI로 CSS에 박힙니다. `build.assetsInlineLimit: 0`으로 껐습니다. [W-002](W-002-main-security-headers.md)의 `data:` 폰트 항목도 이걸로 해소됩니다.
- 2026-10-04 — **리듬.** `Section` 144/88 → 96/64px(개편 전 값). 루프 카드 위 간격 56/64 → 40/48, 원칙 그리드 48/64 → 40/56, 원칙 목록 28 → 20.
- 2026-10-04 — **히어로.** 중앙 정렬 포스터형에서 `lg` 이상 카피 좌·카드 우의 비대칭 2단으로, 전 폭 좌측 정렬. 레코드 마크 → 모노 태그라인 → 제목 락업은 유지. 출시 안내는 앱 토스트 패턴(info 색 점 + 12% 틴트 칩)으로.
- 2026-10-04 — **밀도.** 앱 `SoundCard.tsx`를 그대로 옮긴 세로형 카드(가로×1.42, `--aspect-card`): 사진 없는 카드의 `SoundOnlyPlaceholder`(surfaceElevated 바탕, 84px 레코드, "SOUND-ONLY MEMORY" 9px 모노) 위에 앱과 같은 스크림(deep 82%→10%→90%), 상단 20px 인셋에 eyebrow "FIELD RECORDING"(primary 9px) · 장소명(볼드, 텍스트 그림자) · 길이 배지(검은 68% 알약, 22% 밝은 테두리) · 날짜(모노 12px) · 메모(13px) · 비공개 칩(primaryMuted 위 primary), 하단 16px 인셋에 파형. 뒤에 `WalletCardStack` 규칙(24px 아래, 5% 축소, 15% 투명)으로 카드 둘을 깔고, 마지막은 `MixtapeCardCover`의 violet→surface→deep 대각 그라데이션. 9px 라벨을 위해 `--text-micro`, 커버 위 글자 그림자를 위해 `--text-shadow-cover` 토큰을 추가했습니다. 카드 내용은 예시(장소·날짜·메모)이며 지표·후기가 아닙니다.
- 2026-10-04 — **색 폭.** `violet`(secondary)은 앱에서 믹스테이프 커버에만 쓰이므로 여기서도 스택 맨 뒤 믹스테이프 커버에만. `acid-muted`(primaryMuted)는 앱의 라임 칩 패턴대로 비공개 칩 배경. `info`는 출시 안내 칩. 의미색 전부를 토큰에 넣지는 않았습니다 — 쓰이지 않는 토큰을 두지 않기 위해서입니다.
- 2026-10-04 — **320px 제목.** Gothic A1 Bold가 Pretendard보다 넓어 320px에서 h1이 3줄("듣습니다."가 홀로)로 꺾였습니다. `--text-hero`의 clamp 하한을 34px(2.125rem)에서 32px(2rem)로 내려 두 줄로 되돌렸습니다. 390px에서도 34→32px이 되지만(8vw=31.2px이 하한 아래) 두 줄은 유지됩니다. 768/1440은 60px 그대로.
- 2026-10-04 — **앱 스크린샷.** 사용자가 Play 스토어 스크린샷 다섯 장(`01-capture`, `02-library`, `03-card-detail`, `04-mixtape`, `06-export-preview`)을 넘겼습니다. 앱 저장소 `store/android/screenshots/`의 원본과 `cmp`로 동일함을 확인했고, 각 장이 브랜드 배경 위 영어 헤드라인 + 폰 프레임 캡처로 합성된 창작물이며 OSM 타일(어트리뷰션 필요)과 개인정보가 없고 `01`의 위치명이 이미 익명화돼 있음을 봤습니다. 배치는 세 가지를 저울질했습니다 — 핵심 루프 카드의 커버로 세 장만(자르기 필요, 두 장 남음), 자른 것+전체 갤러리(중복), **자르지 않은 다섯 장을 가로 스크롤 "앱 화면" 절로**(채택: 전부 쓰고, 정본을 손대지 않고, 밀도를 올리며, 섹션 하나 추가로 구조 변화 최소). 핵심 루프 다음·원칙 앞에 넣었습니다. 영어 UI는 한국어 캡션·`alt`로 설명합니다. 사본은 `src/assets/screenshots/*.webp`(720×1280, `cwebp -q 82`), 루트에 복사돼 있던 PNG 다섯 장은 원본이 앱 저장소에 있으므로 제거했습니다. 히어로의 손으로 그린 카드 스택은 그대로 뒀습니다 — 사용자가 적는 장소·메모는 한국어가 자연스럽고, 앱 크롬(FIELD RECORDING, 날짜 형식)은 영어 그대로라 앱과 어긋나지 않습니다.
- 2026-10-04 — **배치 정정.** 사용자가 "별도 섹션이 아니라 기존 섹션의 어울리는 자리"라고 바로잡았습니다. "앱 화면" 절을 지우고 다섯 장을 기존 내용 안으로 옮겼습니다: 히어로 카드 스택 앞장 ← `03-card-detail`(사운드 카드 상세 — "다시 꺼내 듣습니다"에 해당), 핵심 루프 기록 ← `01-capture`, 보관 ← `02-library`+`04-mixtape`(앱 `MixtapeCardCover`의 분할 레이아웃처럼 반씩), 공유 ← `06-export-preview`. 기존 카드 위에 올리면 스토어 프레임의 영어 헤드라인이 한국어 제목과 겹쳐 어색하므로 이번에는 **폰 프레임만** 잘라 씁니다 — 다섯 장의 프레임 위치가 같아(PIL로 테두리 탐지, 다섯 장 모두 x182–898·y407–1833, 717×1427) 좌상단 (170,380)의 740×1480 상자 하나로 잘라 720×1440 WebP(1:2, `--aspect-phone`)로 뒀습니다. 루프 카드 커버는 정사각형에 화면 윗부분을 보여 주고 아랫단 1/3이 surface로 잦아듭니다(앱 SoundCard 커버 스크림). 손으로 그린 히어로 카드와 그것만 쓰던 토큰 `acid-muted`·`micro`·`text-shadow-cover`·`aspect-card`, 그리고 `aspect-screen`을 걷어냈습니다. 섹션은 다시 4개입니다.
- 2026-10-04 — **원칙 제목 문구.** 사용자가 "빠진 기능이 아니라, 내린 결정입니다."가 어색하다고 짚었습니다. 영어 "Not missing features — decisions."의 직역 대구라 "내린 결정입니다"의 주어가 없고, 원칙 목록의 3·4번(비공개 저장과 서명 링크, 원본까지 삭제)은 빠진 기능이 아니라 넣은 장치라 제목이 목록 절반만 설명했습니다. "일부러 그렇게 만들었습니다."로 바꿨습니다 — 없는 것과 있는 것 모두 의도였다는 뜻을 한 문장에 담고 다른 제목들과 같은 합니다체입니다. 대구를 남기는 차선("빠뜨린 게 아니라, 넣지 않았습니다.")은 1·2번만 설명해 택하지 않았습니다. design.md의 문구 점검 항목에서 "대구는 한 번만"의 예시도 갱신했습니다.
- 2026-10-04 — **갤러리 카드 폭.** (폐기된 별도 절에 대한 기록) 처음엔 `sm` 이상 288px였는데 1160px 정렬선 안에 288px 다섯 장이 들어가지 않아 1440px에서 넉 장만 보이고 다섯째의 존재를 알 길이 없었습니다(스크롤바는 숨김). `lg`에서 240px로 줄여 넉 장 + 다섯째 168px이 보이게 했습니다. 모든 폭에서 마지막으로 보이는 카드가 잘려 있어 가로 스크롤 단서가 됩니다.
- 2026-10-04 — **글꼴 비용 측정.** 캐시 없는 첫 방문에 랜딩이 받는 글꼴은 33요청·415KB(Gothic A1 31조각 343KB, Outfit 32KB, JetBrains Mono 40KB), 개인정보처리방침은 30요청·381KB. Pretendard 때(13조각 405KB / 15조각 459KB)와 용량은 비슷하고 요청 수는 늘었습니다. woff 폴백은 한 건도 요청되지 않습니다.

### 검증

- `pnpm build` — 통과. `tokens:check`(`micro`·`aspect-card`·`text-shadow-cover`·`violet`·`acid-muted`·`info` 포함) → `tsc -b` → 클라이언트·SSR → 프리렌더 8페이지. 빌드된 CSS의 `data:` 폰트 0건(`assetsInlineLimit: 0` 효과). 2026-10-04
- computed style(CDP, 320/390/768/1440) — `body`·`h1` 글꼴 `Gothic A1`, h1 700, `document.fonts.check('700 1em "Gothic A1"')` true. 히어로 그리드 `lg` 미만 1열 / 1440에서 2열, h1 `text-align: start`. 카드 비율 1.42(280/350/360px 폭), 22px, 그림자. 뒤 카드 top 24/48px, opacity 0.85/0.7, 맨 뒤에 violet 그라데이션. `text-micro` 9px, 출시 칩 배경 info 12%. 섹션 상단 패딩 64/96px — 전부 의도대로
- 가로 넘침 — 네 폭 모두 `scrollWidth`가 뷰포트와 일치
- 산출물 — `dist/assets` 7.9MB. fontsource CSS가 woff2와 woff 폴백을 함께 선언해 Vite가 둘 다 내보내기 때문(594개). 브라우저는 unicode-range에 맞는 woff2 조각만 받으므로 페이지 용량과는 무관하고, 배포 artifact 크기만 커진다. 실제 다운로드 용량은 위 '글꼴 비용 측정' 참고
- 히어로 제목 줄 수(CDP, `--text-hero` 하한 32px 적용 후) — 320/390/768/1440 모두 2줄, 320px 우측 끝 300px
- 화면(CDP 에뮬레이션) — 데스크톱 1440 히어로·전체 페이지, 모바일 390·320: 좌측 정렬 2단 히어로, Gothic A1의 둥근 결, 세로형 카드의 사실들(eyebrow·장소·배지·날짜·메모·칩·파형)과 뒤 카드 띠, 64/96 리듬. 이상 없음
- 앱 화면 절 `pnpm build` — 통과(`aspect-screen` 토큰 포함). WebP 다섯 장이 `dist/assets/`에 해시 이름으로 20–24KB씩, 합계 108KB. `tsconfig.app.json`이 이미 `vite/client`를 참조해 `.webp` import 타입은 별도 선언 없이 통과(실수로 만든 `src/vite-env.d.ts`는 되돌림)
- 앱 화면 절 computed(CDP, 320/390/768/1440) — 섹션 5개, `ul` `overflow-x: auto` + `scroll-snap-type: x mandatory`, `ul.scrollWidth` 1384/1568 > `clientWidth`인데 문서 `scrollWidth`는 네 폭 모두 뷰포트와 일치(스크롤러 안에 갇힘). 다섯 `img` 모두 로드(720×1280), `alt`·`width`·`height` 있음, 렌더 254×452(모바일)/286×508(≥sm)/240×427(≥lg)
- 앱 화면 절 스크롤 단서 — 폭별로 마지막에 보이는 카드의 잘린 폭: 390px 118, 768px 137, 1024px 229, 1440px 168(다섯째)
- 앱 화면 절 화면 — 1440 섹션, 390 섹션, 1440 전체 페이지 확인. 스토어 프레임이 카드 레시피 안에서 한국어 캡션과 함께 읽힘. 이상 없음 (이 절은 이후 사용자 정정으로 폐기)
- 배치 정정 뒤 `pnpm build` — 통과(`aspect-phone` 토큰, 걷어낸 토큰 다섯 개 참조 잔존 0건). 잘라낸 WebP 다섯 장 24–28KB, 합계 136KB
- 배치 정정 뒤 computed(CDP, 320/390/768/1440) — 섹션 4개, 문서 `scrollWidth`가 네 폭 모두 뷰포트와 일치, `img` 5개 전부 로드(720×1440)·`alt`·`width`/`height` 있음. 히어로 이미지 1:2(278–286px 폭), `loading="eager"` + `fetchpriority="high"`. 루프 커버 정사각(278/348/222/374px), 보관 카드의 분할 커버 두 칸 폭 동일(139/174/111/187px)
- 배치 정정 뒤 화면 — 1440 히어로·핵심 루프·전체 페이지, 390 히어로·핵심 루프 확인. 히어로 오른쪽에 실제 사운드 카드 상세 화면이 스택 앞장으로, 루프 카드 셋은 화면 윗부분이 커버로 들어가 surface로 잦아들고, 보관 카드에는 라이브러리와 믹스테이프 폰 두 대가 반씩. 이상 없음
